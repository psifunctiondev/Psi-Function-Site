TruRender Overview

TruRender converts Enscape / architectural renders into photorealistic images using a ComfyUI + Flux.1-dev pipeline on Modal (A100 80GB). Each project takes an architectural render as input and returns a photorealistic photograph that preserves geometry, colours, and materials while replacing materials and lighting with photographic detail.

Process summary (full UI lands in R2): you upload a render, choose a preset, and TruRender produces a photograph. Each render is recorded with its parameters and result so you can compare presets side-by-side.
